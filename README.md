# Swipe & Bite

Swipe & Bite is a food discovery app that lets users swipe through restaurants and recipes and save the ones they like.

## Purpose

The goal of Swipe & Bite is to make deciding what to eat easier and more visual.

Users can browse two main sections:

- Cook at Home
- Eat Out

They can swipe left to skip an option or swipe right to save it.

## Features

- Swipe through restaurants
- Swipe through recipes
- Save restaurants
- Save recipes
- View saved items
- Filter by category
- View restaurant details
- View recipe details
- View saved restaurants on an interactive map
- Filter saved restaurants by city
- Use current location to compare saved restaurants
- Get directions to restaurants
- Keep saved items after refresh using localStorage

## New Technique

The main new technique I learned in this project was using Leaflet to create an interactive map.

Each restaurant has latitude and longitude coordinates. When a user saves a restaurant, the app can use those coordinates to place a marker on the map.

This allows users to visually see where their saved restaurants are and compare their locations.

## Why I Added the Map

The map feature came from a problem I had while traveling.

I had saved a lot of restaurants, but I could not easily tell which ones were closest to me.

I wanted Swipe & Bite to make saved restaurants more useful by showing them visually on a map.
