# Reflection

Swipe & Bite was built from my own ideas. I came up with the overall concept, the swipe format, the Cook at Home and Eat Out sections, the Saved section, the map feature, the travel use case, and the photo requirements. AI helped me figure out how to turn those ideas into working code, explain unfamiliar concepts, and debug problems, but the product decisions and user experience came from me.

The main new technique I learned in Project Zed was how to build an interactive map using Leaflet. Before this project, I did not know how latitude and longitude could be used to place restaurant markers on a map. I learned how saved restaurants could be matched with coordinates, displayed as markers, filtered by city, and compared with a user's current location.

The map feature was also my idea. I came up with it because I had experienced the problem myself while traveling. I had saved a lot of restaurants, but I could not easily tell which one was closest to me. I wanted Swipe & Bite to solve that problem by letting users see their saved restaurants visually on a map.

AI helped me understand and debug the code, but it could not make the important design decisions for me. I decided what features I wanted, what problems the app should solve, what photos were acceptable, how the swipe experience should feel, and what information should be visible before someone swipes.

I also wanted to add restaurant star ratings to the swipe cards so users could see a rating before deciding yes or no. I could not find a reliable way to add legitimate ratings for every exact restaurant location without making up data or using an API I did not have access to. I decided it was better to leave the ratings out than include inaccurate information.

The project also taught me that AI-generated code still needs to be tested carefully. Several features looked correct in VS Code but behaved differently on GitHub Pages. I had to test the app, identify the exact problem, revise my prompts, and decide which fixes made sense for my app.

One thing this project showed me is that AI can help build an idea, but it does not decide what the idea should be. The ideas, features, and user experience for Swipe & Bite came from me. AI was a tool that helped me build and troubleshoot them.
